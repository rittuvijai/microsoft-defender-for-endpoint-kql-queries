# Security Configuration Assessment — Microsoft Defender for Endpoint KQL Queries

KQL query for pulling every failed **Threat & Vulnerability Management (TVM) secure configuration assessment** check on Windows Servers, with category, risk description, benchmark mapping (CIS, etc.), and remediation guidance.

| Query | What it answers |
|---|---|
| [`windows-server-security-configuration-assessment.kql`](windows-server-security-configuration-assessment.kql) | Every applicable, failed security configuration check per server, with how-to-fix guidance |
