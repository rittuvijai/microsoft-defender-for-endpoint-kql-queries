# Device Inventory by OS — Microsoft Defender for Endpoint KQL Queries

KQL queries for a deduplicated, 90-day **device inventory** broken out by operating system — useful for asset management, onboarding planning, and shadow IT discovery.

| Query | What it answers |
|---|---|
| [`windows-devices-inventory.kql`](windows-devices-inventory.kql) | Inventory of non-server Windows devices |
| [`macos-devices-inventory.kql`](macos-devices-inventory.kql) | Inventory of macOS devices |
| [`linux-devices-inventory.kql`](linux-devices-inventory.kql) | Inventory of Linux devices |
| [`android-devices-inventory.kql`](android-devices-inventory.kql) | Inventory of Android devices |
