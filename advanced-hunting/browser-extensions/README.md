# Browser Extension Risk — Microsoft Defender for Endpoint KQL Queries

KQL query for finding **medium/high-risk browser extensions** (Chrome, Firefox, Edge) installed on Windows Servers — a common lateral-movement and data-exfiltration blind spot on server workloads that shouldn't be browsing the web.

| Query | What it answers |
|---|---|
| [`risky-browser-extensions-on-servers.kql`](risky-browser-extensions-on-servers.kql) | Which servers have risky browser extensions installed, and which ones? |
